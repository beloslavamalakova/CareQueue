# IQL Score – README

## Overview

The file `iql_score.py` computes a **patient-level evaluation score** from a trained Implicit Q-Learning (IQL) model.

Instead of evaluating full trajectories, it evaluates:

> **How good is the patient’s condition at ICU admission, according to the model?**

This is done using the learned **value function** \( V(s) \).

---

## Core Idea

IQL learns a value function:

\[
V(s)
\]

which estimates the expected future outcome from a state.

This script:
1. Extracts the **first state (initial ICU condition)** for each patient
2. Computes \( V(s_0) \)
3. Uses this as a model predicted **patient-level score**

## Applying This to Other Models

This scoring framework can be adapted to other RL models.

For BCQ / DDQN, for the Q-function we can use predicted_value = max(Q(s, a))

And for Behavior Cloning (BC) since does not learn a value function, these are the options:

Use action probabilities, i.e. learn the likelihood of each action being taken
Or train a separate value head
